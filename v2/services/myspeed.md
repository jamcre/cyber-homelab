# MySpeed

Network speed testing and history tracking deployed as an LXC container on pavilion.

---

## 📋 Container Specs

| Property | Value                        |
| :------- | :--------------------------- |
| CT ID    | 102                          |
| Hostname | `myspeed`                    |
| Template | Proxmox VE Helper Script     |
| VLAN     | 20 — Lab                     |
| IP       | 192.168.20.XX/24             |
| Gateway  | 192.168.20.1                 |
| Web UI   | `https://myspeed.jamcre.dev` |

---

## ⚙️ Installation

Installed using the Proxmox VE Helper Scripts from the Proxmox shell.
